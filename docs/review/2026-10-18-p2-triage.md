## copy-bytes-after-trailer-ignored [bq-iceberg] — CONFIRMED · data-loss-or-wrong-value · fix accepted · unit-test

- evidence: wire/bqparquet.rs:612-618 `while !self.finished { ... if trailer { self.finished = true; } ... }`.
